# Restaurant Order Management API

A RESTful API built with Node.js, Express.js, and MongoDB for managing restaurant menu items and customer orders.

## Features

- Menu CRUD operations
- Order management
- Order status updates
- Filtering by category and availability
- MongoDB database integration
- Input validation

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv
- cors
